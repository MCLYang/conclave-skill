# Chair Synthesis — R2

## 分歧关闭情况

### 分歧点1：硬底限 R2 vs R3 → 已收敛
R2 结束后各方立场：
- Claude(A)：从全局R3让步到"分级底线"（高风险R3，低风险账本零未结项时允许R2终止）
- Codex(B)、Qwen(D)、Chair(E)：动态终止最早从R3开始评估
- Gemini(C)：坚持R2硬底限

**收敛点：**全体同意"至少完成R1+R2，动态终止最早从R3开始评估"。Claude 的分级底线与此兼容（高风险保留R3，低风险经验证后可下调）。Gemini 的抗议已被其他四位覆盖。

### 分歧点2：决策权结构 → 收敛方向已明确
全体同意"主席不应单点最终决定"。具体机制存在多种可行表达，属于设计级细节：
- Claude：主席提议 + 无人挂起未结项（默示同意）
- Codex：主席裁定 + 三层约束（账本清零、反方异议窗口、用户否决）
- Gemini：主席提议 + 关键少数否决权
- Qwen：主席动议 + 反对方确认 + 用户否决
- Chair：分层决策（账本无战略级/结构级开放 + 无新增分歧 + 无结构级熔断 + 用户未否决）

**差异已降级为"如何称呼这套机制"，而非"是否分散决策"。**

### 分歧点3：新增分歧率 → 4:1，可裁决
Claude、Codex、Qwen、Chair 均支持纳入。Gemini 反对机械化定义，但未反对"新增分歧"本身作为判断维度。
Qwen 提出了精确化方案：主席归类实质性新增 vs 重述性新增 + 分歧溯源程序防策略性延迟。

**裁决：纳入终止条件，但保持定性判断标准（主席归类+溯源），不写死代码逻辑。**
